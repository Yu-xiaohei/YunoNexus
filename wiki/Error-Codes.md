# YUNO Nexus 错误码体系

> 版本: 0.1.0  
> 日期: 2026-07-04

---

## 错误码格式：`XYYY`

| 位数 | 含义 | 取值范围 |
|------|------|----------|
| 第1位 | 服务/模块 | 1-9 |
| 第2位 | 错误类型 | 0-9 |
| 第3-4位 | 具体编号 | 01-99 |

---

## 第1位 - 服务/模块

| 代码 | 模块 |
|------|------|
| 1 | 认证中间件 |
| 2 | 注册/登录 |
| 3 | 用户管理 |
| 4 | 设备管理 |
| 5 | 隧道管理 |
| 6 | 流量统计 |
| 7 | 配置管理 |
| 8 | 管理员 |
| 9 | 系统/代理 |

## 第2位 - 错误类型

| 代码 | 类型 |
|------|------|
| 0 | 参数错误 |
| 1 | 认证失败 |
| 2 | 权限不足 |
| 3 | 资源不存在 |
| 4 | 资源冲突 |
| 5 | 频率限制 |
| 6 | 状态异常 |
| 7 | 依赖服务错误 |
| 8 | 业务逻辑错误 |
| 9 | 系统内部错误 |

## 完整错误码列表

### 1xxx - 认证中间件

| 错误码 | HTTP状态码 | 提示文本 | 触发场景 |
|--------|------------|----------|----------|
| 1001 | 401 | 缺少认证令牌 | 请求头没有Authorization字段 |
| 1002 | 401 | 认证令牌格式错误 | Authorization不是"Bearer xxx"格式 |
| 1003 | 401 | 认证令牌无效或已过期 | JWT签名验证失败或token已过期 |
| 1021 | 403 | 权限不足，需要管理员权限 | 非admin角色访问管理员接口 |

## 响应格式

### 成功
```json
{
  "code": 0,
  "message": "success",
  "data": { ... },
  "timestamp": "2026-07-04T00:00:00Z"
}
```

### 错误
```json
{
  "code": 2011,
  "message": "您的账号或密码输入错误",
  "timestamp": "2026-07-04T00:00:00Z"
}
```

## 快速排查指南

| 现象 | 错误码范围 | 排查方向 |
|------|------------|----------|
| 登录失败 | 2011, 2012, 2013, 2051, 2061 | 检查密码/两步验证/账号状态/锁定 |
| 注册失败 | 2001, 2002, 2041, 209x | 检查参数/密码强度/用户名重复/数据库 |
| 设备操作失败 | 4021-4023, 4031, 409x | 检查设备归属/设备是否存在/数据库 |
| 隧道操作失败 | 5021-5024, 5031, 5071, 5081, 509x | 检查隧道归属/端口池/数量限制/数据库 |
| 权限不足 | 1021, 402x, 502x | 检查用户角色/资源归属 |
| Token问题 | 1001, 1002, 1003, 2014, 2015 | 检查Token格式/过期/签名 |

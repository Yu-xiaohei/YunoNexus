# YUNO Nexus 错误码体系

> 版本: 0.1.0  
> 日期: 2026-07-04

---

## 错误码格式：`XYYY`

| 位数 | 含义 | 取值范围 |
|------|------|----------|
| 第1位 | 服务/模块 | 1-9 |
| 第2位 | 错误类型 | 0-9 |
| 第3-4位 | 具体编号 | 01-99 |

---

## 第1位 - 服务/模块

| 代码 | 模块 |
|------|------|
| 1 | 认证中间件 |
| 2 | 注册/登录 |
| 3 | 用户管理 |
| 4 | 设备管理 |
| 5 | 隧道管理 |
| 6 | 流量统计 |
| 7 | 配置管理 |
| 8 | 管理员 |
| 9 | 系统/代理 |

## 第2位 - 错误类型

| 代码 | 类型 |
|------|------|
| 0 | 参数错误 |
| 1 | 认证失败 |
| 2 | 权限不足 |
| 3 | 资源不存在 |
| 4 | 资源冲突 |
| 5 | 频率限制 |
| 6 | 状态异常 |
| 7 | 依赖服务错误 |
| 8 | 业务逻辑错误 |
| 9 | 系统内部错误 |

```json

  "code": 0,
  "message": "success",
  "data": { ... },
  "timestamp": "2026-07-04T00:00:00Z"
}
```

```json
{
  "code": 2011,
  "message": "您的账号或密码输入错误",
  "timestamp": "2026-07-04T00:00:00Z"
}
```

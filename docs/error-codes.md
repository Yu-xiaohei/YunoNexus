## 错误码规则

| 错误码范围 | 含义 |
|------------|------|
| 0 | 成功 |
| 1xxx | 认证/权限错误 |
| 2xxx | 业务逻辑错误 |
| 9xxx | 系统内部错误 |

## 密码强度规则

- 最少8个字符
- 必须包含 **字母、数字、特殊符号** 中的**至少两种**
- 例如合法：`Abc12345`（字母+数字）、`Pass@word`（字母+特殊符号）、`12345!@#`（数字+特殊符号）
- 例如不合法：`abcdefgh`（只有字母）、`12345678`（只有数字）

API 接口文档

基础信息

  • 基础路径: /api/v1
  • 认证方式: Bearer Token (JWT)
  • 内容类型: application/json

认证接口

方法路径说明
POST/api/v1/auth/register注册新用户
POST/api/v1/auth/login用户登录
POST/api/v1/auth/refresh刷新Token

用户接口

方法路径说明
GET/api/v1/users/me获取当前用户信息

设备接口

方法路径说明
GET/api/v1/devices设备列表
GET/api/v1/devices/:id设备详情
PUT/api/v1/devices/:id更新设备
DELETE/api/v1/devices/:id吊销设备

隧道接口

方法路径说明
GET/api/v1/tunnels隧道列表
POST/api/v1/tunnels创建隧道
GET/api/v1/tunnels/:id隧道详情
PUT/api/v1/tunnels/:id更新隧道
DELETE/api/v1/tunnels/:id删除隧道
POST/api/v1/tunnels/:id/start启动隧道
POST/api/v1/tunnels/:id/stop停止隧道
GET/api/v1/tunnels/:id/stats隧道统计

流量接口

方法路径说明
GET/api/v1/traffic/overview流量概览
GET/api/v1/traffic/tunnel/:id按隧道查询流量

配置接口

方法路径说明
GET/api/v1/config/export导出配置
POST/api/v1/config/import导入配置

管理员接口

方法路径说明
GET/api/v1/admin/users用户列表
PUT/api/v1/admin/users/:id更新用户
GET/api/v1/admin/system/stats系统统计
GET/api/v1/admin/audit-logs审计日志
GET/api/v1/admin/system/config系统配置
PUT/api/v1/admin/system/config更新系统配置
